The line between the two

STRIDE-Lite-v2.0 is the public Apache 2.0 tool: STRIDE, DREAD, and kill-chain scenarios you can run locally.

Contingency Atlas is a different product — a fuller foresight stack (ingest, signals, judged scenarios, radar). It does not ship in this repository and cannot be treated as open-source from this project.

No Atlas data, methods, or internals are included here. The shared look is deliberate kinship, not a bundle.
